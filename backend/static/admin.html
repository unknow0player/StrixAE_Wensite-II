替换音频

支持 WAV / FLAC / OGG / MP3，最多 25 MB、120 秒，8–96 kHz，单/双声道。播放副本统一为 WAV；频谱按原脚本在 16 kHz 下生成。

首次生成可能需要较长时间，请等待结果。Mixture 的频谱仅在后台显示，以保留展示页原布局。
